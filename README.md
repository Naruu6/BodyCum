# BodyCum

![BodyCum cover](docs/images/bodycum-cover.jpg)

BodyCum adds extra controls to **Status → Juices** in Koikatsu CharaStudio. Set the color, opacity, density, and brightness for each character, then pick which hair, accessories, and clothes get the effect.

## Get started

1. Close CharaStudio and get `BodyCum.dll` from the [1.0 release](https://github.com/Naruu6/BodyCum/releases/tag/v1.0.0).
2. Put it in `BepInEx/plugins` under your Koikatsu folder.
3. Open CharaStudio, select a character, and go to **Status → Juices**.

You'll need Windows, Direct3D 11, BepInEx 5, KKAPI 1.42.1 or later, and Extended Save. See the [installation guide](docs/INSTALL.md) for links and setup.

## In Studio

- Use **BodyCum** for the selected character and the **F1** master switch for all characters.
- Pick **Off**, **x1**, or **x2** for Belly, Tongue, Hair, Accessory, and Clothes. Hair, accessories, and clothes have slot, position, and size controls.
- The pattern follows accessories and clothes as they move. Save the scene to keep their placement.
